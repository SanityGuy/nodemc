<h1 align="center">NodeMC</h1>
<p align="center">Custom minecraft plugin made by <b>SouyanDev</b></p>
<br>

### Description
This plugin is made for testing and fun aswell as to test several plugins 
in the custom local server of <b>NodeMC</b> currently locally hosted.
</br>

### Stack & Libraries
<ul>
<li>Java 27</li>
<li>Docker</li>
<li>PaperMC 26.3</li>
</ul>
