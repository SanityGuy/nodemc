<h1 align="center">NodeMC</h1>
<p align="center">Custom lightweight plugin made by <b>SouyanDev</b></p>

### Description
This plugin is made for testing and fun aswell as to test several plugins 
in the custom local server of <b>NodeMC</b> currently locally hosted.
</br>

### Stack & Libraries
<ul>
<li>Java 27</li>
<li>Docker</li>
<li>PaperMC 26.3</li>
</ul>

### Contributions
Currently as the plugin is developing, contributions will be open
and accepted as plugin ideas and implementations with credits.

### Additional Information
For anyone wondering if I would release this plugin, answer is no. but this plugin will always
remain open-sourced and open for submissions for the upcoming <b>NodeMC Demo</b> server.
